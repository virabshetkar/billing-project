# Billing Project

This is a simply billing project to understand the architecture of working with multiple relational entities and also to understand how to effectively use the newer features of angular and @angular/cdk in order to deliver a custom made UI.

There are 4 main folders including this one for the documentation:

1. server: A .NET Web API.
2. client: An Angular Application.
3. infra: Contains necessary files to replicate the external dependent services. (Ex: A PostgresSQL Server).
4. docs: Documentation using mkdocs with material.
